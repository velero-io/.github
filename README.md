# .github

Default [community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) and organization profile for the [Velero](https://velero.io) project.

## What this repo provides

Files in this repository are used as org-wide defaults for all repositories under the [velero-io](https://github.com/velero-io) organization. If a repository does not have its own copy of a file, GitHub will use the version from this repo.

### Community health files

- `CODE_OF_CONDUCT.md` - CNCF Code of Conduct
- `CONTRIBUTING.md` - Contribution guidelines
- `SECURITY.md` - Security vulnerability reporting process
- `SUPPORT.md` - How to get help
- `GOVERNANCE.md` - Project governance, roles, and decision-making process

### Issue and PR templates

- `ISSUE_TEMPLATE/bug_report.md` - Bug report template
- `ISSUE_TEMPLATE/feature-enhancement-request.md` - Feature request template
- `pull_request_template.md` - Pull request template

### Organization profile

- `profile/README.md` - Displayed on the [velero-io organization page](https://github.com/velero-io)
